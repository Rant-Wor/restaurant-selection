Objective (เป้าหมาย)

เป้าหมายของ Workflow: ค้นหา วิเคราะห์ ให้คะแนน และแนะนำร้านอาหารที่เหมาะสำหรับทีม 8–12 คน ในพื้นที่ที่กำหนด (สยาม, อารีย์, ทองหล่อ, อโศก, พร้อมพงษ์) โดยอิงจากข้อมูลจริงที่ตรวจสอบได้ เพื่อใช้เป็นตัวเลือกสำหรับมื้อเย็นหลังเลิกงาน

Workflow Overview (ภาพรวมขั้นตอน)

1. Data Collection (Scraping)

ดึงข้อมูลร้านอาหารดิบผ่าน Apify (Google Maps Scraper)

2. AI Analysis & Scoring

ใช้ OpenAI GPT 5-mini ในการประเมินและให้คะแนนตามเกณฑ์ 100 คะแนน

3. Automation Workflow

เชื่อมต่อข้อมูลทั้งหมดและจัดการคิวด้วย n8n ส่งข้อมูลไปยัง Google Sheets

4. Output (HTML Report)

นำเสนอข้อมูลในรูปแบบ HTML Dashboard สไตล์ Minimal Luxury ที่สามารถโต้ตอบได้

Tools Used (เครื่องมือที่ใช้)

Apify
OpenAI GPT 5-mini
n8n (Automation)
Google Sheets
HTML/CSS/JS

Data Sources (แหล่งข้อมูล)

แหล่งข้อมูลURLหมายเหตุ
Google Maps (via Apify) Apify Google Maps แหล่งข้อมูลรีวิว, เรตติ้ง และเวลาทำการ
Google Sheets (Database) Published CSV ฐานข้อมูลที่ผ่านการประมวลผลแล้ว

Scoring Criteria (เกณฑ์การให้คะแนน)

หมวดหมู่คะแนนเต็มเกณฑ์การพิจารณา
Rating20คะแนนเฉลี่ยบน Google Maps และจำนวนรีวิว (ความน่าเชื่อถือ)
Group20พื้นที่กว้างขวาง เหมาะกับการคุยงาน/สังสรรค์ (8-12 คน)
Price15ความคุ้มค่า (VFM) ไม่เกิน 1,500 บาท/คน
Travel15ใกล้ BTS/MRT หรือมีที่จอดรถเพียงพอ
Data15ความสมบูรณ์ของข้อมูล (เวลาเปิดปิด, เบอร์โทร)
Unique15จุดเด่นเฉพาะตัว (บรรยากาศ, รสชาติ, โปรโมชัน)
รวมทั้งหมด100คัดเลือกเฉพาะร้านที่มีคะแนนรวมสูงสุด
